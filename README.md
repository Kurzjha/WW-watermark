# WW-watermark

Консольная программа на C++17 накладывает полупрозрачное BMP-изображение на исходное и сохраняет результат в новый BMP-файл.

## Возможности

- Чтение и запись несжатых 24-битных BMP (Windows Bitmap v3).
- Корректная обработка выравнивания строк BMP и ориентации изображения.
- Наложение водяного знака по центру исходного изображения с прозрачностью 30%.
- Понятные сообщения об ошибках при неверных аргументах, проблемах чтения/записи и несовместимых размерах.

Водяной знак может быть меньше исходного изображения, но не больше него. Меняются только пиксели области водяного знака. Цвет каждого пикселя вычисляется по формуле `result = original * (1 - alpha) + watermark * alpha`, где по умолчанию `alpha = 0.3`.

## Сборка

Требуются CMake 3.16 или новее и компилятор с поддержкой C++17.

```sh
cmake -S . -B build
cmake --build build
```

Исполняемый файл будет создан в каталоге `build` (в Windows обычно `build/Debug/ww-watermark.exe` при конфигурации Visual Studio).

## Запуск

```sh
ww-watermark <original.bmp> <watermark.bmp> <output.bmp>
```

Например:

```sh
./build/ww-watermark original.bmp watermark.bmp result.bmp
```

Необязательный четвёртый аргумент задаёт прозрачность водяного знака от `0.0` до `1.0`:

```sh
./build/ww-watermark original.bmp watermark.bmp result.bmp 0.4
```

В Windows укажите путь к исполняемому файлу, например `build\Debug\ww-watermark.exe`. Входные изображения должны быть несжатыми 24-битными BMP. Программа размещает водяной знак по центру и записывает обработанное изображение в указанный выходной файл.

## Структура проекта

- `include/BMPImage.h`, `src/BMPImage.cpp` — загрузка, доступ к пикселям и сохранение BMP.
- `include/Watermark.h`, `src/Watermark.cpp` — смешивание пикселей для водяного знака.
- `src/main.cpp` — разбор аргументов командной строки и запуск обработки.
- `tests/test_watermark.cpp` — автоматическая проверка чтения BMP, padding строк, порядка пикселей, смешивания и сохранения результата.
- `.github/workflows/c-cpp.yml` — сборка проекта в GitHub Actions при push и pull request в `main` или `master`.

## Проверки

Тесты запускаются вместе со сборкой CMake через CTest:

```sh
ctest --test-dir build --output-on-failure
```

Тест создаёт небольшие BMP-файлы, проверяет смешивание пикселя 50/50, размещение метки по центру, сохранение неизменённых пикселей и обратную загрузку созданного файла. В корне также лежат примеры `images.bmp`, `watermark.bmp` и `result.bmp`; запуск для их повторного создания:

```sh
./build/ww-watermark images.bmp watermark.bmp result.bmp
```

## Ограничения и возможные улучшения

Сейчас поддерживаются только несжатые 24-битные BMP с заголовком `BITMAPINFOHEADER`. В дальнейшем можно добавить поддержку других глубин цвета и форматов, настройку прозрачности и выбор положения водяного знака.
